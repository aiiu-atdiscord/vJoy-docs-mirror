# vJoyList

<small>Original archived at: https://web.archive.org/web/20180326174436/http://vjoystick.sourceforge.net/site/index.php/utilities-218/vjoylist</small>

This utility lists vJoy Devices and lets you see at a glance the Installed and the Aquired devices.

It also tells you which process has acquired each vJoy device.

Usefull when you want to tell which feeder owns which device.

![](<List vJoy Devices.jpg>)

## Usage

Greyed-out devices are not cofigured.

Black device numbers represent configured devices that are not acquired

Red device numbers represent configured devices that are owned (acquired) by an application whose process number appear on the second column.
