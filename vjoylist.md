# vJoyList

<small>Original archived at: https://web.archive.org/web/20180326174436/http://vjoystick.sourceforge.net/site/index.php/utilities-218/vjoylist</small>

This utility lists vJoy Devices and lets you see at a glance which devices are Installed or Acquired.

It also tells you which process has acquired which vJoy device.

Useful when you want to tell which feeder owns which device.

![](<List vJoy Devices.jpg>)

## Usage

Greyed-out devices are not configured.

Black device numbers represent configured devices that are not acquired.

Red device numbers represent configured devices that are owned (acquired) by an application whose process number appears on the second column.
