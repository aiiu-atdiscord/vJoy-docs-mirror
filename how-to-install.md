# How to Install

<small>Original archived at: https://web.archive.org/web/20180331173515/http://vjoystick.sourceforge.net/site/index.php/download-a-install/how-to-install</small>

Download and execute the installer. The installation is straightforward. It may take a few minutes so wait patiently for the success message.

In case the installation failed, please post your problem in the forum. Attach two log files:

1. The log file for the Inno Setup wrapper is called **Setup Log 2011-11-01 #<ins>xxx</ins>.txt** and is located under %TEMP% folder. (**<ins>xxx</ins>** can be any number in the range 001-999).
2. The log file for the executable is called v**JoyInstall.log** and located in the vJoy folder (C:/Program Files/vJoy).

**The latest driver is now signed!**
